# Кнопка "Разбор" в главном меню

## Цель

Добавить в главное меню бота отдельную кнопку `Разбор`, которая открывает уже существующее меню разборов.

## Решение

- Добавляем кнопку `Разбор` в `start_reply_keyboard()` главного меню.
- Переиспользуем существующий сценарий входа в разбор.
- Расширяем хендлер входа в разбор так, чтобы он принимал и `Пойти в разбор`, и `Разбор`.

## Почему так

- Нет дублирования логики.
- Старый путь из диагностики продолжает работать без изменений.
- Изменение локальное и не затрагивает остальную навигацию.
